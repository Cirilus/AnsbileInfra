three_x_ui
=========

Installs `3x-ui` on Ubuntu using the official manual installation steps from
the upstream wiki, without the interactive `install.sh`.

Requirements
------------

- The role currently supports Ubuntu hosts only.
- Installation runs only when `3x-ui` is missing, when
  `three_x_ui_force_install=true`, or when `three_x_ui_version` is set and
  does not match the installed version.

Role Variables
--------------

- `three_x_ui_version`: install a specific version, empty string keeps current version once installed.
- `three_x_ui_force_install`: rerun installer even if `3x-ui` is already installed.
- `three_x_ui_port`: optional panel port.
- `three_x_ui_username` and `three_x_ui_password`: optional admin credentials. If omitted,
  the role generates them once, stores them in `.artifacts/three_x_ui/<host>/`,
  and prints them in the play output.
- `three_x_ui_web_base_path`: optional custom web base path. If omitted,
  the role generates a random path like `/abc123.../`, stores it in
  `.artifacts/three_x_ui/<host>/`, and prints it in the play output.
- `three_x_ui_show_current_settings`: print `x-ui setting -show` after installation.

Example Playbook
----------------

```yaml
- hosts: servers
  roles:
    - role: three_x_ui
      three_x_ui_port: "2053"
      three_x_ui_username: "admin"
      three_x_ui_password: "strong-password"
      three_x_ui_web_base_path: "/panel-secret/"
```

Autogenerated credentials example:

```yaml
- hosts: servers
  roles:
    - role: three_x_ui
      three_x_ui_port: "2053"
```
